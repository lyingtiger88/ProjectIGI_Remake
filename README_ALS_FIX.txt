ProjectIGI_Remake - ALS integration repair
==========================================

The player class is now a project-owned AAlsCharacter subclass with ALS character/movement settings, mesh, animation blueprint, Enhanced Input bindings, and a stable third-person SpringArm camera.

Build:
- Unreal Engine 5.8
- Generate Visual Studio project files
- Build ProjectIGI_RemakeEditor / Development Editor / Win64
- Open the project and Play the Third Person map

The ALS plugin is tracked as an external dependency/submodule; binary Unreal assets are not stored in this source-only repository.
