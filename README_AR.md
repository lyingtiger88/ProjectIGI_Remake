# ProjectIGI Remake (العربية)

[English](README.md) | [فارسی](README_FA.md) | **العربية** | [Русский](README_RU.md)

مشروع **ProjectIGI Remake** هو نموذج لعبة تصويب تكتيكية من منظور الشخص الثالث مع أنظمة قتال قريب (CQC) مبني باستخدام Unreal Engine 5.8.

## التقنيات

- Unreal Engine 5.8
- C++ للأنظمة الأساسية والذكاء الاصطناعي
- Blueprint لإعداد المحتوى
- ALS Refactored لنظام الحركة
- BDFR Interactive AI لأنظمة الذكاء الاصطناعي والتتبع

## الأنظمة الحالية

- شخصية لاعب مبنية على ALS
- كاميرا منظور ثالث
- Enhanced Input
- نظام آثار الأقدام والرائحة
- تتبع الذكاء الاصطناعي البشري والكلاب
- فصل أنظمة الحركة والقتال والذكاء الاصطناعي

## البناء

المتطلبات:

- Unreal Engine 5.8
- Visual Studio 2022 مع دعم C++
- Git مع Submodules

الاستنساخ:

```bash
git clone --recurse-submodules https://github.com/lyingtiger88/ProjectIGI_Remake.git
```
