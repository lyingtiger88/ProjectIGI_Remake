# ProjectIGI Remake (فارسی)

[English](README.md) | **فارسی** | [العربية](README_AR.md) | [Русский](README_RU.md)

پروژه **ProjectIGI Remake** یک نمونه تیراندازی تاکتیکی سوم‌شخص و Close Quarter Combat است که با Unreal Engine 5.8 توسعه داده می‌شود.

## تکنولوژی‌ها

- Unreal Engine 5.8
- C++ برای سیستم‌های اصلی، هوش مصنوعی و Gameplay
- Blueprint برای تنظیمات محتوا و Iteration سریع
- ALS Refactored برای Locomotion
- BDFR Interactive AI برای سیستم‌های هوش مصنوعی، ردپا و بو

## سیستم‌های فعلی

- شخصیت بازیکن مبتنی بر ALS
- دوربین سوم‌شخص
- Enhanced Input
- سیستم Footprint و Scent Tracking
- AI انسانی و Canine Tracking
- معماری جدا برای Combat، AI و Locomotion

## ساخت پروژه

نیازمندی‌ها:

- Unreal Engine 5.8
- Visual Studio 2022 با C++ Desktop Development
- Git با پشتیبانی Submodule

کلون کردن:

```bash
git clone --recurse-submodules https://github.com/lyingtiger88/ProjectIGI_Remake.git
```
