# ProjectIGI Remake (Русский)

[English](README.md) | [فارسی](README_FA.md) | [العربية](README_AR.md) | **Русский**

**ProjectIGI Remake** — это прототип тактического шутера от третьего лица с элементами Close Quarter Combat, созданный на Unreal Engine 5.8.

## Технологии

- Unreal Engine 5.8
- C++ для игровых систем, AI и ядра проекта
- Blueprint для настройки контента
- ALS Refactored для системы движения
- BDFR Interactive AI для систем восприятия, следов и запахов

## Реализованные системы

- Игрок на базе ALS
- Камера от третьего лица
- Enhanced Input
- Система следов и запахов
- AI противников и собак
- Разделение Locomotion, Combat и AI

## Сборка

Требования:

- Unreal Engine 5.8
- Visual Studio 2022 с поддержкой C++
- Git Submodules

Клонирование:

```bash
git clone --recurse-submodules https://github.com/lyingtiger88/ProjectIGI_Remake.git
```
